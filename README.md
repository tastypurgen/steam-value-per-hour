# Steam Value Per Hour

Небольшое расширение для Chromium-браузеров. На странице игры Steam оно ждёт
данные HowLongToBeat от Augmented Steam и показывает текущую стоимость одного
часа для `Main Story`, `Story and Extras` и `Completionist`. Также показывает
стоимость часа по цене SteamDB: используется `2-year low`, если он есть, иначе
`lowest recorded price`.

## Установка

1. Установите и включите расширение Augmented Steam с опцией HowLongToBeat.
2. Откройте `chrome://extensions` (в Edge — `edge://extensions`).
3. Включите **Режим разработчика**.
4. Нажмите **Load unpacked / Загрузить распакованное** и выберите папку
   `steam-value-per-hour`.
5. Откройте или обновите страницу игры в Steam.

Расширение не запрашивает разрешений, не отправляет данные в сеть и использует
только уже отображённые Steam и Augmented Steam данные.

## Ограничения

- Метрика является ориентиром: она использует `Main Story`, а не личное время
  прохождения.
- Нужны доступные данные HLTB и ненулевая цена игры.
- Если Augmented Steam изменит разметку, может потребоваться обновить парсер в
  `content.js`.
